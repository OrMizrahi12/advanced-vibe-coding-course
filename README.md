# Advanced Vibe Coding — Course Materials

Official companion repository for **Advanced Vibe Coding: Terminal Agents, Tmux Fleets, Loop Engineering & Shipping to Production**.

Every lesson has its own numbered folder containing starter files, configuration templates, shell scripts, cheat sheets, and reference checkpoints so you can follow along on your own machine or jump directly into any section.

## Structure

- `01-01-from-chatbots-to-terminal-commanders/` — Section 1, Lesson 1 starter materials & reference guide
- *(Additional lesson folders are organized by `<section>-<lesson>-<slug>/` matching the course syllabus.)*

## Prerequisites

- Linux, macOS, or Windows (WSL2) terminal
- Git 2.30+
- Node.js 20+ (LTS)
- `jq` and `tmux` (installed step-by-step during Section 1 and Section 2)
- A personal Google account for Google Antigravity CLI (`agy`) free tier
