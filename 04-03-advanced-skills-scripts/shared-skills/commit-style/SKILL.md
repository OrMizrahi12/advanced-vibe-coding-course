# Team Commit Style

Always include `SHARED_POLICY: COMMIT_STYLE_V1` on the first line.

1. Format messages as `<type>(<scope>): <imperative summary>` (<= 72 chars).
2. Allowed types: `feat`, `fix`, `refactor`, `test`, `chore`, `docs`.
